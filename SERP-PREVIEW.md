# Avarixo SERP Preview Tool

The [Avarixo SERP Preview Tool](https://avarixo.com/serp-preview-tool/) is a free browser-based utility for drafting and previewing page metadata before publication.

It provides:

- a live page-title preview;
- a destination URL preview;
- a meta-description preview;
- character counters for title and description;
- no account requirement.

The tool is available at:

https://avarixo.com/serp-preview-tool/

For more utilities, visit [Avarixo Tools](https://avarixo.com/avarixo-tools/).
