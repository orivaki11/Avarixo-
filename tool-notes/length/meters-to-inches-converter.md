## When to convert

Useful for comparing dimensions in international product specifications, construction plans and distance records. The input uses **meters** and the result uses **inches**; check these units before comparing values.

## Conversion rule

Multiply the input in meters by 39.37007874 to obtain inches.

## Python 3 worked check

```python
value = 2
converted = value * 39.37007874
print(round(converted, 6))
```

**Example:** 2 meters ≈ **78.74015748 inches**. The code rounds its printed result for display only.
