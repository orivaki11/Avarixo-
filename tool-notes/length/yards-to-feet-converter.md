## When to convert

Useful for comparing dimensions in international product specifications, construction plans and distance records. The input uses **yards** and the result uses **feet**; check these units before comparing values.

## Conversion rule

Multiply the input in yards by 3 to obtain feet.

## Python 3 worked check

```python
value = 3
converted = value * 3
print(round(converted, 6))
```

**Example:** 3 yards ≈ **9 feet**. The code rounds its printed result for display only.

## Accuracy notes

The conversion uses international length definitions (one inch is exactly 0.0254 meter). The original instrument's precision limits how many result digits are meaningful.
