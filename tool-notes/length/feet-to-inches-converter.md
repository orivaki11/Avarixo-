## When to convert

Useful for comparing dimensions in international product specifications, construction plans and distance records. The input uses **feet** and the result uses **inches**; check these units before comparing values.

## Conversion rule

Multiply the input in feet by 12 to obtain inches.

## Python 3 worked check

```python
value = 3
converted = value * 12
print(round(converted, 6))
```

**Example:** 3 feet ≈ **36 inches**. The code rounds its printed result for display only.

## Accuracy notes

The conversion uses international length definitions (one inch is exactly 0.0254 meter). The original instrument's precision limits how many result digits are meaningful.
