## When to convert

Useful for comparing dimensions in international product specifications, construction plans and distance records. The input uses **inches** and the result uses **centimeters**; check these units before comparing values.

## Conversion rule

Multiply the input in inches by 2.54 to obtain centimeters.

## Python 3 worked check

```python
value = 12
converted = value * 2.54
print(round(converted, 6))
```

**Example:** 12 inches ≈ **30.48 centimeters**. The code rounds its printed result for display only.

## Accuracy notes

The conversion uses international length definitions (one inch is exactly 0.0254 meter). The original instrument's precision limits how many result digits are meaningful.
