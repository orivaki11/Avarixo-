# Avarixo Tools — reproducible examples and field notes

This directory is a companion collection of **100 practical worked notes** for the [Avarixo free online tools catalog](https://avarixo.com/avarixo-tools/). It is organized for developers, learners and people who want to independently check a conversion or calculation. Each entry contains the live Avarixo tool, a small reproducible Python 3 example, and limitations.

These are reference examples, not a claim that the original websites execute the same Python code. This is an Avarixo-maintained directory rather than independent third-party endorsements.
