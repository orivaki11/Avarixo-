## When to convert

Useful for checking product weights, parcel limits, ingredient masses and gym measurements. The input uses **grams** and the result uses **ounces**; check these units before comparing values.

## Conversion rule

Multiply the input in grams by 0.03527396195 to obtain ounces.

## Python 3 worked check

```python
value = 500
converted = value * 0.03527396195
print(round(converted, 6))
```

**Example:** 500 grams ≈ **17.636980975 ounces**. The code rounds its printed result for display only.

## Accuracy notes

The example uses avoirdupois mass units. A mass ounce is different from a fluid ounce; the defined international pound is 0.45359237 kilogram.
