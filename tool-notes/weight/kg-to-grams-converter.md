## When to convert

Useful for checking product weights, parcel limits, ingredient masses and gym measurements. The input uses **kilograms** and the result uses **grams**; check these units before comparing values.

## Conversion rule

Multiply the input in kilograms by 1000 to obtain grams.

## Python 3 worked check

```python
value = 2
converted = value * 1000
print(round(converted, 6))
```

**Example:** 2 kilograms ≈ **2000 grams**. The code rounds its printed result for display only.

## Accuracy notes

The example uses avoirdupois mass units. A mass ounce is different from a fluid ounce; the defined international pound is 0.45359237 kilogram.
