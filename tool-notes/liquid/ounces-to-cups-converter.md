## When to convert

Useful for recipes, beverage quantities and container capacities when regional conventions are identified. The input uses **ounces** and the result uses **U.S. customary cups**; check these units before comparing values.

## Conversion rule

Multiply the input in ounces by 0.125 to obtain U.S. customary cups.

## Python 3 worked check

```python
value = 8
converted = value * 0.125
print(round(converted, 6))
```

**Example:** 8 ounces ≈ **1 U.S. customary cups**. The code rounds its printed result for display only.

## Accuracy notes

The example uses U.S. customary volume units; an imperial gallon or an international 'cup' may have a different definition. Fluid ounces measure volume rather than mass.
