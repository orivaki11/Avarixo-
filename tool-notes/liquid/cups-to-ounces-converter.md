## When to convert

Useful for recipes, beverage quantities and container capacities when regional conventions are identified. The input uses **U.S. customary cups** and the result uses **ounces**; check these units before comparing values.

## Conversion rule

Multiply the input in U.S. customary cups by 8 to obtain ounces.

## Python 3 worked check

```python
value = 2
converted = value * 8
print(round(converted, 6))
```

**Example:** 2 U.S. customary cups ≈ **16 ounces**. The code rounds its printed result for display only.

## Accuracy notes

The example uses U.S. customary volume units; an imperial gallon or an international 'cup' may have a different definition. Fluid ounces measure volume rather than mass.
