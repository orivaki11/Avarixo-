## When to convert

Useful for recipes, beverage quantities and container capacities when regional conventions are identified. The input uses **liters** and the result uses **milliliters**; check these units before comparing values.

## Conversion rule

Multiply the input in liters by 1000 to obtain milliliters.

## Python 3 worked check

```python
value = 2
converted = value * 1000
print(round(converted, 6))
```

**Example:** 2 liters ≈ **2000 milliliters**. The code rounds its printed result for display only.

## Accuracy notes

The example uses U.S. customary volume units; an imperial gallon or an international 'cup' may have a different definition. Fluid ounces measure volume rather than mass.
