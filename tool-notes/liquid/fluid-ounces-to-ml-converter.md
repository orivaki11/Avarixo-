## When to convert

Useful for recipes, beverage quantities and container capacities when regional conventions are identified. The input uses **U.S. fluid ounces** and the result uses **milliliters**; check these units before comparing values.

## Conversion rule

Multiply the input in U.S. fluid ounces by 29.573529562 to obtain milliliters.

## Python 3 worked check

```python
value = 8
converted = value * 29.573529562
print(round(converted, 6))
```

**Example:** 8 U.S. fluid ounces ≈ **236.5882365 milliliters**. The code rounds its printed result for display only.

## Accuracy notes

The example uses U.S. customary volume units; an imperial gallon or an international 'cup' may have a different definition. Fluid ounces measure volume rather than mass.
