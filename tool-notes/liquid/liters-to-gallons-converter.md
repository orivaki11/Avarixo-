## When to convert

Useful for recipes, beverage quantities and container capacities when regional conventions are identified. The input uses **liters** and the result uses **U.S. liquid gallons**; check these units before comparing values.

## Conversion rule

Multiply the input in liters by 0.26417205236 to obtain U.S. liquid gallons.

## Python 3 worked check

```python
value = 2
converted = value * 0.26417205236
print(round(converted, 6))
```
