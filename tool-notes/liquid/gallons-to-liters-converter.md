## When to convert

Useful for recipes, beverage quantities and container capacities when regional conventions are identified. The input uses **U.S. liquid gallons** and the result uses **liters**; check these units before comparing values.

## Conversion rule

Multiply the input in U.S. liquid gallons by 3.785411784 to obtain liters.

## Python 3 worked check

```python
value = 2
converted = value * 3.785411784
print(round(converted, 6))
```
