## What this solves

Compute triangular area using base and perpendicular height. The code below is a small **independent example**, intended as a sanity check rather than the implementation of the live website.

## Python 3 example

```python
base_cm, height_cm = 10, 4
print(base_cm * height_cm / 2)
```

**Illustrative result:** 20 square centimeters.

## Interpret carefully

The height must be perpendicular to the selected base. Change the example inputs and check the magnitude, units, rounding and assumptions. The [Avarixo Triangle Area](https://avarixo.com/triangle-area-calculator/) offers a browser interface for trying your own values; review its on-page instructions before relying on a result.
