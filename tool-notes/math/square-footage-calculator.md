## What this solves

Calculate area of a rectangular floor in square feet. The code below is a small **independent example**, intended as a sanity check rather than the implementation of the live website.

## Python 3 example

```python
length_ft, width_ft = 12, 10
print(length_ft * width_ft)
```

**Illustrative result:** 120 square feet.

## Interpret carefully

Irregular rooms need decomposition into shapes; material purchase estimates may also need waste. Change the example inputs and check the magnitude, units, rounding and assumptions.
