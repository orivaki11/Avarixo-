## What this solves

Find the smallest nonnegative common multiple of two integer values. The code below is a small **independent example**, intended as a sanity check rather than the implementation of the live website.

## Python 3 example

```python
from math import lcm
print(lcm(6, 8))
```

**Illustrative result:** 24.
