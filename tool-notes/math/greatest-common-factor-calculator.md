## What this solves

Find the largest positive divisor shared by two integers. The code below is a small **independent example**, intended as a sanity check rather than the implementation of the live website.

## Python 3 example

```python
from math import gcd
print(gcd(24, 36))
```

**Illustrative result:** 12.
