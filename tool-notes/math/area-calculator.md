## What this solves

Compute the area of a rectangle from compatible linear measurements. The code below is a small **independent example**, intended as a sanity check rather than the implementation of the live website.

## Python 3 example

```python
length_m, width_m = 8, 5
area_m2 = length_m * width_m
print(area_m2)
```

**Illustrative result:** 40 square meters.

## Interpret carefully

A linear measurement factor cannot be reused unchanged for area; check the shape. Change the example inputs and check the magnitude, units, rounding and assumptions. The [Avarixo Area Calculator](https://avarixo.com/area-calculator/) offers a browser interface for trying your own values; review its on-page instructions before relying on a result.
