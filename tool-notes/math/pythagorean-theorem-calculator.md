## What this solves

Determine the hypotenuse of a right triangle from its legs. The code below is a small **independent example**, intended as a sanity check rather than the implementation of the live website.

## Python 3 example

```python
from math import hypot
a, b = 3, 4
print(hypot(a, b))
```

**Illustrative result:** 5 length units.
