# Avarixo Web Tools

Avarixo publishes free browser-based utilities for everyday web tasks.

## Tool directory

- [Avarixo Tools](https://avarixo.com/avarixo-tools/) — the main directory of calculators, converters, text tools and browser utilities.
- [SERP Preview Tool](https://avarixo.com/serp-preview-tool/) — preview a page title, URL and meta description in a search-result style layout.
- [Word Counter](https://avarixo.com/word-counter/) — count words and characters in text.
- [Character Counter](https://avarixo.com/character-counter/) — fast browser-based character counting.
- [Image Resizer](https://avarixo.com/image-resizer/) — resize images in the browser.
- [Color Picker](https://avarixo.com/color-picker/) — pick and inspect colors.
- [Random Number Generator](https://avarixo.com/random-number-generator/) — generate random numbers.
- [Mortgage Calculator](https://avarixo.com/mortgage-calculator/) — calculate mortgage payments.

Avarixo's tools are intended to be simple, direct and usable without unnecessary setup. The canonical index is maintained at https://avarixo.com/avarixo-tools/.
