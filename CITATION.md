# How to cite Avarixo data

Avarixo Original Data: https://avarixo.com/avarixo-original-data/

When reusing an Avarixo-created score, AVX identifier, normalized ranking, classification, or compiled snapshot, cite the specific dataset page and snapshot ID.

## Dataset pages

- Avarixo AI Model Tracker — https://avarixo.com/avarixo-ai-model-tracker/
- Avarixo Gaming Update Tracker — https://avarixo.com/avarixo-gaming-update-tracker/
- Avarixo Trending Games Index — https://avarixo.com/avarixo-trending-games-index/
- Avarixo Streaming Release Tracker — https://avarixo.com/avarixo-streaming-release-tracker/
- Avarixo Product Recall Tracker — https://avarixo.com/avarixo-product-recall-tracker/

Example citation:

> Avarixo Trending Games Index, snapshot AVX-TREND-2026-10-13-v15, Avarixo, 13 October 2026, https://avarixo.com/avarixo-trending-games-index/

Underlying facts and source data remain attributable to the first-party sources identified on each dataset page.
