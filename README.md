## SERP Preview

This repository also contains a free browser tool for drafting a page title and meta description and previewing how the text may look in a search result.

### Use it

Open `index.html` in a modern browser. The tool runs locally in your browser; it does not send your text to a server.

### What it does

- Shows a search-result style preview as you type.
- Counts title and description characters as rough drafting guides.
- Lets you preview a destination URL and copy the text.
- Works without dependencies, an account, or an API key.

Search engines may display different title links or snippets, and can truncate text based on the query, device, and available width. The preview is illustrative, not a guarantee of how a search result will appear.

## Citation

When reusing an Avarixo-created score, AVX identifier, normalized ranking, or compiled snapshot, cite the relevant dataset page and snapshot ID. See [CITATION.md](CITATION.md).

## Privacy

The SERP Preview processes input in the browser tab and does not store or transmit the text you enter.
