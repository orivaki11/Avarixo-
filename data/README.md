# Avarixo data mirrors

These files are lightweight machine-readable mirrors of selected Avarixo Original Data snapshots.

Canonical data hub: https://avarixo.com/avarixo-original-data/

## Files

- `catalog.csv` — current public Avarixo dataset catalog and canonical URLs.
- `trending-games-2026-10-13.csv` — Avarixo Trending Games Index snapshot AVX-TREND-2026-10-13-v15.

For methodology, source links, limitations, and version history, use the canonical Avarixo dataset page:
https://avarixo.com/avarixo-trending-games-index/
