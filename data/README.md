# Avarixo data mirrors

These files are lightweight machine-readable mirrors of selected Avarixo Original Data snapshots.

Canonical data hub: https://avarixo.com/avarixo-original-data/
Citation and downloads: https://avarixo.com/cite-avarixo-data/

## Files

- `catalog.csv` — public Avarixo dataset catalog and canonical URLs.
- `ai-model-tracker-2026-10-13.csv` — AI Model Tracker snapshot.
- `gaming-update-tracker-2026-10-13.csv` — Gaming Update Tracker snapshot.
- `trending-games-2026-10-13.csv` — Trending Games Index snapshot AVX-TREND-2026-10-13-v15.
- `streaming-release-tracker-2026-10-13.csv` — Streaming Release Tracker snapshot.
- `product-recall-tracker-2026-10-13.csv` — Product Recall Tracker snapshot.

For methodology, first-party source links, limitations, and version history, use each canonical Avarixo dataset page.
